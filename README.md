# Geração Caldeira 2026 — Programação Java

Repositório que reúne projetos, exercícios e aplicações desenvolvidos durante minha participação no **Geração Caldeira 2026**, na trilha de **Programação Java**.

Este espaço registra minha evolução ao longo da formação, reunindo projetos práticos e conhecimentos adquiridos durante a jornada.

## Sobre o Geração Caldeira

O Geração Caldeira é um programa de formação e preparação para o mercado de tecnologia promovido pelo **Instituto Caldeira**.

Na trilha de Programação Java, os projetos deste repositório acompanham diferentes etapas do aprendizado, desde os fundamentos da linguagem até a construção de aplicações.

Este repositório representa parte da minha trajetória de aprendizado durante o **Geração Caldeira 2026**.

A proposta é registrar projetos, experimentos e conhecimentos adquiridos ao longo da formação, acompanhando minha evolução na área de tecnologia.
